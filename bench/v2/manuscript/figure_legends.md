# Main-figure legends

**Figure 1 | The dotbio bundle architecture.** A `.bio` bundle is a directory holding four kinds of artifact: `facts/` (immutable JSON observations keyed by the SHA-256 of their canonical form, sharded by the first two hex characters), `commits/` (an append-only log of ruleset applications, each commit naming a parent and a `name@version` ruleset and emitting a list of claims), `views/` (materialized phenotype-level Markdown summaries with embedded `claim_id` HTML comments for drill-down), and `refs/` (text files holding a single commit ID; `HEAD` is required, additional named refs such as `stable` are optional). `manifest.json` is the entry point: it lists views with `est_tokens`, the active rulesets with version and source URL, and the current refs map. The reading protocol funnels from manifest down to view, claim, ruleset and only then to underlying facts; consumers MUST resolve through `commits/` and never read `facts/` directly.

**Figure 2 | Round-1 cross-format token cost on the NA12878 8-locus PGx-VIP panel.** Bar chart of input token counts measured with the Xenova/claude-tokenizer for seven equivalent representations of the same eight PharmGKB Tier-1 loci: `.genome` reconstruction (663 tokens), VCF (676), `.bio` manifest+view (834), Phenopackets v2 (4,001), PharmCAT JSON (5,168), and FHIR R4 Genomics bundle (13,887). The dashed horizontal line marks `.bio` (1.00×). `.bio` is the smallest format among those that carry a structured, machine-auditable evidence chain (rulesets table + claim-level guideline citation + fact hashes); only narrative formats (raw VCF, prose `.genome`) are smaller, and both fail the audit-citation criterion in panel B (Figure 3). Source: `bench/results/tokens.json`, `bench/v2/data/format_*`, `bench/v2/TASKS.md` round-1 status table.

**Figure 3 | Single-shot correctness on a CPIC-grounded clopidogrel question (NA12878).** For each of four formats (VCF, VCF + PharmCAT-style ruleset, `.genome` reconstruction, `.bio` manifest+view), a fresh general-purpose LLM agent with a strict no-tools instruction was given only the format text plus the question "Can NA12878 take clopidogrel safely at standard dose?" and asked to return a structured response (verdict, phenotype, diplotype, guideline citation, variant evidence, self-reported external inference). Heatmap rows score: verdict ("depends" matches CPIC@2022 IM guidance), phenotype ("Intermediate Metabolizer"), guideline-cited-with-version, variant-evidence-cited, no-external-inference. All four formats reached the correct verdict; only the VCF + ruleset and `.bio` cells score 1 on guideline-with-version. Source: `bench/results/llm_eval.json`. *N=1 single-shot per cell; round-2 will multiply by 30 replicates × 4 LLMs.*

**Figure 4 | 24-month longitudinal cohort: SoC quarterly re-annotation versus `.bio` monthly update.** Cumulative-actionable-reclassifications-captured curve over 24 monthly ClinVar snapshots (synthetic transitions sampled per Landrum 2018 + Harrison & Rehm 2019 background rates) for 5 patients × 24 months × ~5,500-position panel. The arm_soc trajectory plateaus below ground truth (20 of 47 actionable transitions captured, FNR 0.574, mean detection latency ≈1 month conditional on capture); the arm_bio trajectory tracks ground truth exactly (47 of 47, FNR 0.000, latency 0). Cumulative read cost: 5,374 tokens (SoC) versus 12,754 tokens (`.bio`), a 2.37× cost for catching every reclassification. Inset: per-patient FNR. Source: `bench/v2/results/exp04_longitudinal_smoke.json`. *Synthetic ClinVar archive in round-1; round-2 will use the real 24-month NCBI FTP archive.*

**Figure 5 | Privacy, robustness, performance, and multi-omics generalizability.** Four small panels. **(a) Re-identification attack surface (Erlich–Narayanan, N=10⁵ panel)**: marker count and fingerprint entropy in bits for `vcf_raw` (8 markers, 4.74 bits), `genome_reconstruction` (7, 5.62 bits), `bio_facts_with_public_ruleset` (8, 4.74 bits — same as VCF, since under a public ruleset the hash leaks the same dosage information), `bio_facts_hash_only` (0 markers, 0 bits — SHA-256 pre-image resistance dominates), `bio_views_only` (2 collapsed phenotype markers, 1.59 bits). The two `.bio` sharing modes that withhold the ruleset or share only views strictly dominate VCF on attack surface entropy. **(b) Adversarial robustness**: 29/29 fuzz cases pass across `vcf` (11/11), `rulesets` (7/7), `schema` (7/7), and `hashes` (4/4). **(c) Performance on the 11-variant synthetic example**: cold compile 18.3 ms, warm 10.3 ms median; bundle 7.4 KB compressed; `bio show pgx` p95 < 1 ms over 100 runs; `bio update` median 2.6 ms. **(d) Methylation extension pilot (Horvath clock)**: same `facts/`–`commits/`–`views/`–`refs/` structure on β-value array data, 353/353 probes carried, evidence chain complete, demo predicted age 35.33 y. Sources: `bench/v2/results/exp06_reid_risk.json`, `exp07_adversarial.json`, `exp05_perf.json`, `exp08_methylation.json`.
